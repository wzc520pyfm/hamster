# Hamster (provisional name)

This is a bounded P0 exploration, not a product release. "Hamster" is a provisional name. The trademark has not been searched, and this repository is not a public launch.

P0 checks whether a self-hosted control plane, a React web client, independent task lifecycles, persistent OpenUI pages, and fail-closed approvals can be built on a replaceable execution engine. Eve is evaluated first. This is not the first public version, and it is not authorization to publish or to promote the project.

## Status

Implementation is in progress. See the self-hosting section once Compose is working.

## Self-hosting

Instructions will be added after the local or single-host Compose path (control plane + React client + required database) is verified. The acceptance story must complete without commercial hosted services from Vercel, eve, or OpenUI.
